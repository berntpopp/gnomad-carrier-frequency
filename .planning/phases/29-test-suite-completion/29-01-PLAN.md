       - Add `@vitejs/plugin-vue` plugin
       - Set `test.name: 'web'`, `test.environment: 'jsdom'`
       - Set `test.setupFiles: ['./src/test/setup.ts']`
       - Set `test.include: ['src/**/*.test.ts']`
       - Set coverage config:
         - `provider: 'v8'`
         - `reporter: ['text', 'json']`
         - `include: ['src/**/*.{ts,vue}']`
         - `exclude: ['src/test/**', 'src/main.ts', 'src/api/client.ts', 'src/vite-env.d.ts']`
         - Thresholds all set to 0 (warn-only — actual targets documented in comments: web 40%+)
       - CRITICAL: Mirror all three alias groups from `apps/web/vite.config.ts` exactly:
         ```
         resolve.alias = [
           { find: '~gene-configs', replacement: '../../configs/genes' (via fileURLToPath) },
           { find: /^@gnomad-cf\/core(\/.*)?$/, replacement: '../../packages/core/src' + '$1' },
           { find: '@', replacement: './src' },
         ]
         ```
       - These aliases are the #1 failure point — without them, all imports fail.

    3. Create `apps/web/src/test/setup.ts`:
       - Import `beforeAll` and `vi` from vitest
       - Import `createVuetify` from `vuetify`, `* as components` from `vuetify/components`, `* as directives` from `vuetify/directives`, and `'vuetify/styles'`
       - Export `const vuetify = createVuetify({ components, directives })`
       - In `beforeAll`:
         - Mock `global.ResizeObserver` with vi.fn returning { observe, unobserve, disconnect } stubs
         - Mock `window.matchMedia` returning standard mock (matches: false, media: query, all listener methods as vi.fn())
         - Set `window.location` to `{ href: 'http://localhost:5173/' }` (writable)

    4. Create `apps/web/src/test/helpers.ts`:
       - Import `mount` and `MountingOptions` from `@vue/test-utils`
       - Import `createTestingPinia` and `TestingOptions` from `@pinia/testing`
       - Import `vuetify` from `./setup`
       - Export `mountWithPlugins(component, options?)` function that:
         - Accepts optional `piniaOptions` (TestingOptions), `storeInitialState` (Record<string, unknown>), and rest of MountingOptions (props, slots, etc.)
         - Returns `mount(component, { global: { plugins: [vuetify, createTestingPinia({ stubActions: true, initialState: storeInitialState, ...piniaOptions })] }, ...rest })`
       - This helper eliminates boilerplate in every component test.

    5. Verify the setup works by running:
       ```
       cd /path/to/repo && bun run test --filter gnomad-cf-web --passWithNoTests
       ```
       Should exit 0 with "no test files" (no tests yet, but config resolves correctly).
