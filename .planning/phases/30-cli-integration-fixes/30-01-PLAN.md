    **Issue 3 — Delegate prevalence to core in gene-query.ts (lines 244-247):**

    Add `calculateGeneticPrevalence` and `calculateBayesianPrevalence` to the existing import from `@gnomad-cf/core/calculations` (line 19-26).

    Then replace the inline math:
    ```typescript
    // BEFORE (inline):
    const geneticPrevalence = globalSumAF > 0 ? globalSumAF * globalSumAF : null
    const bayesianPrevalence =
      geneticPrevalence !== null ? geneticPrevalence * calcConfig.penetrance : null

    // AFTER (delegated to core):
    const pathogenicAFs: number[] = []
    for (const v of variants) {
      const ac = (v.exome?.ac ?? 0) + (v.genome?.ac ?? 0)
      const an = (v.exome?.an ?? 0) + (v.genome?.an ?? 0)
      if (an > 0) pathogenicAFs.push(ac / an)
    }
    const geneticPrevalence = pathogenicAFs.length > 0 ? calculateGeneticPrevalence(pathogenicAFs) : null
    const bayesianPrevalence =
      geneticPrevalence !== null && geneticPrevalence > 0
        ? calculateBayesianPrevalence(geneticPrevalence, calcConfig.penetrance)
        : null
    ```

    IMPORTANT: The `computeGlobalStats` function already has the `variants` and `globalSumAF` in scope. Since `calculateGeneticPrevalence` takes an array of AFs and sums them internally, and we already have `globalSumAF` as that sum, the simplest correct delegation is:

    ```typescript
    const geneticPrevalence = globalSumAF > 0 ? calculateGeneticPrevalence([globalSumAF]) : null
    const bayesianPrevalence =
      geneticPrevalence !== null && geneticPrevalence > 0
        ? calculateBayesianPrevalence(geneticPrevalence, calcConfig.penetrance)
        : null
    ```

    This is numerically identical (calculateGeneticPrevalence sums the array and squares it; with a single element, that's globalSumAF^2) but delegates to the canonical core functions. Use this simpler form — it matches how `frequency-calc.ts` calls it (line 168: `calculateGeneticPrevalence([data.sumAF])`).

    **Understanding the fixture:** The CFTR fixture has 3 variants:
    1. `7-117559593-ATCT-A` — frameshift, LoF HC, ClinVar Pathogenic (4 stars)
    2. `7-117548628-G-A` — missense, NOT LoF, ClinVar Pathogenic (3 stars)
    3. `7-117531061-A-G` — missense, NOT LoF, ClinVar Uncertain significance (1 star) — always filtered out

    With default filters (lofHcEnabled=true, clinvarEnabled=true, clinvarStarThreshold=2): variants 1 and 2 pass. Count = 2.

    **Test cases:**

    1. `'default filters include both LoF and ClinVar variants (count=2)'`
       - Call queryGene with default FACTORY_FILTER_DEFAULTS
       - Assert variantCount === 2

    2. `'--no-lof (lofHcEnabled=false) excludes the LoF-only pathway and may reduce count'`
       - Call queryGene with `{ ...FACTORY_FILTER_DEFAULTS, lofHcEnabled: false }`
       - Variant 1 is LoF HC AND ClinVar P (4 stars >= threshold 2), so it still passes via ClinVar path
       - Variant 2 is ClinVar P only (3 stars >= threshold 2), still passes
       - Assert variantCount === 2 (in this fixture both variants have ClinVar P, so disabling LoF alone doesn't reduce count)
       - This still validates the property name is correct — if it were wrong, TypeScript would complain (now that typecheck covers CLI)

    3. `'--no-clinvar (clinvarEnabled=false) reduces variant count'`
       - Call queryGene with `{ ...FACTORY_FILTER_DEFAULTS, clinvarEnabled: false }`
       - Only LoF HC variants pass now: variant 1 (frameshift, LoF HC). Variant 2 (missense, no LoF) is excluded.
       - Assert variantCount === 1

    4. `'--no-lof --no-clinvar excludes all variants'`
       - Call queryGene with `{ ...FACTORY_FILTER_DEFAULTS, lofHcEnabled: false, clinvarEnabled: false }`
       - No variants pass either filter
       - Assert variantCount === 0

    5. `'high star threshold (4) reduces ClinVar matches'`
       - Call queryGene with `{ ...FACTORY_FILTER_DEFAULTS, clinvarStarThreshold: 4 }`
       - Variant 1: LoF HC (passes via LoF) AND ClinVar P with 4 stars (passes)
       - Variant 2: missense, ClinVar P with 3 stars < 4 (fails star threshold), no LoF (fails) → excluded
       - Assert variantCount === 1

    6. `'filter flags produce different globalCarrierFrequency values'`
       - Query with defaults → get cf1
       - Query with clinvarEnabled: false → get cf2
       - Assert cf1 !== cf2 (different variant counts → different frequencies)
