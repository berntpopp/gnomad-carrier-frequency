**1. Create `public/sitemap.xml`** (SEO-04):
Hand-crafted sitemap for the SPA (single URL). Place in `public/` so Vite copies it to dist root at build time.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url>
    <loc>https://gnomad-carrier-frequency.kidney-genetics.org/</loc>
    <changefreq>monthly</changefreq>
    <priority>1.0</priority>
  </url>
</urlset>
```

**2. Update `public/robots.txt`** (SEO-05):
Replace current content with:

```
User-agent: *
Allow: /

Sitemap: https://gnomad-carrier-frequency.kidney-genetics.org/sitemap.xml
Sitemap: https://gnomad-carrier-frequency.kidney-genetics.org/docs/sitemap.xml
```

**3. Configure VitePress sitemap** (SEO-09):
In `docs/.vitepress/config.ts`, add sitemap configuration and OG image head tags. The hostname MUST include the `/docs/` base path (VitePress known issue #3863 -- it does not auto-append base).

Add to the `defineConfig` object:
```typescript
sitemap: {
  hostname: 'https://gnomad-carrier-frequency.kidney-genetics.org/docs/',
},
lastUpdated: true,
```

Also update the `head` array to include OG image meta tags for the docs site (shared OG image with the app, referenced via absolute URL):
```typescript
head: [
  ['link', { rel: 'icon', href: '/favicon.svg' }],
  ['meta', { property: 'og:image', content: 'https://gnomad-carrier-frequency.kidney-genetics.org/og-image.png' }],
  ['meta', { property: 'og:image:width', content: '1200' }],
  ['meta', { property: 'og:image:height', content: '630' }],
  ['meta', { property: 'og:image:type', content: 'image/png' }],
  ['meta', { name: 'twitter:card', content: 'summary_large_image' }],
  ['meta', { name: 'twitter:image', content: 'https://gnomad-carrier-frequency.kidney-genetics.org/og-image.png' }],
],
```
