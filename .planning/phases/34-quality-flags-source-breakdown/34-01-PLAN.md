    6. Create `packages/core/src/filters/quality-flags.ts` with:
       - Import `GnomadVariant` from types, `QualityFlag`, `QualitySettings`, `QualityExclusionConfig` from quality types
       - `isHighAF(variant: GnomadVariant, threshold: number): boolean` -- checks if global AF >= threshold. Use joint-first pattern: `variant.joint?.ac / variant.joint?.an` falling back to `(exome.ac + genome.ac) / (exome.an + genome.an)`. Also check per-population AFs -- if ANY population has AF >= threshold, flag it (per Pitfall 3 in RESEARCH.md). For per-population check, iterate `variant.joint?.populations` (or exome+genome populations), compute `ac/an` for each, flag if any >= threshold.
       - `isHighHom(variant: GnomadVariant, settings: QualitySettings): boolean` -- if method is 'hwe_relative': compute `expectedHom = AF^2 * AN` using joint-first data, flag if `observedHom > expectedHom * settings.highHomHWEMultiplier`. If method is 'absolute': flag if `observedHom >= settings.highHomAbsoluteThreshold`. Use joint-first pattern for AC, AN, homozygote_count (per Pitfall 2 in RESEARCH.md).
       - `isGnomadFiltered(variant: GnomadVariant): boolean` -- returns true if `variant.exome?.filters?.length > 0 || variant.genome?.filters?.length > 0`. Filter values like 'PASS' or empty array means passed; non-empty non-PASS means failed. Actually gnomAD uses: variants that PASS have filters = [] or filters = ["PASS"]. Variants that FAIL have filters containing specific filter names (e.g., "RF", "AC0", "InbreedingCoeff"). So check: `filters.length > 0 && !filters.every(f => f === 'PASS')`. Handle undefined/null gracefully.
       - `isGenomesOnly(variant: GnomadVariant): boolean` -- returns true if no exome data but has genome data. Check: `(variant.exome === undefined || variant.exome === null || variant.exome.an === 0) && (variant.genome !== undefined && variant.genome !== null && variant.genome.an > 0)`. Note: if variant has `joint` data, it means both exome and genome contributed, so it is NOT genomes-only. Only flag if no `joint` AND no exome.
       - `computeQualityFlags(variant: GnomadVariant, settings: QualitySettings): QualityFlag[]` -- master function calling each check, building array of QualityFlag objects with label, explanation, severity. Severity mapping: high_af = 'critical', high_hom = 'warning', gnomad_filtered = 'warning', genomes_only = 'info'. Explanation text should be informative -- see RESEARCH.md code examples for wording.
       - `shouldExcludeByQuality(flags: QualityFlag[], exclusionConfig: QualityExclusionConfig): boolean` -- returns true if any flag type matches an active exclusion toggle. E.g., if flags includes 'high_af' and exclusionConfig.excludeHighAf is true, return true.
       - `flagSeverityColor(severity: 'critical' | 'warning' | 'info'): string` -- returns Vuetify color name: 'critical' -> 'error', 'warning' -> 'warning', 'info' -> 'blue-grey'. Also export `flagTypeColor(type: QualityFlagType): string` for per-type colors: high_af -> 'error' (red), high_hom -> 'orange' (orange), gnomad_filtered -> 'amber' (yellow), genomes_only -> 'blue-grey'.
