Create `packages/core/src/orphanet/types.ts` with these types (verified API shapes from RESEARCH.md):

- `OrphanetGeneResult`: `{ ORPHAcode: number; 'Preferred term': string; OrphanetURL: string; Date: string; DisorderGeneAssociation: OrphanetGeneAssociation[] }`
- `OrphanetGeneAssociation`: `{ DisorderGeneAssociationType: string; DisorderGeneAssociationStatus: string; Gene: { Symbol: string; name: string; GeneType: string; ExternalReference: Array<{ Source: string; Reference: string }> } }`
- `OrphanetPrevalenceEntry`: `{ PrevalenceClass: string; PrevalenceGeographic: string; PrevalenceType: string; PrevalenceQualification: string; PrevalenceValidationStatus: string; Source: string; ValMoy: string }`
- `OrphanetDisease`: `{ orphacode: number; name: string; orphanetUrl: string; isAutosomalRecessive: boolean; bestPrevalence: { prevalenceClass: string; geographic: string; validationStatus: string; valMoy: number } | null }`
- `OrphanetResult`: `{ geneSymbol: string; diseases: OrphanetDisease[]; fetchedAt: number; error: string | null }`

Create `packages/core/src/orphanet/client.ts` with:

1. `ORPHANET_BASE = 'https://api.orphadata.com'` and `FETCH_TIMEOUT_MS = 5000` constants.

2. `fetchWithTimeout(url: string, timeoutMs?: number): Promise<Response>` -- uses AbortController + setTimeout for 5-second timeout. On abort or network error, throw. clearTimeout in both success and failure paths.

3. `fetchDiseasesByGeneSymbol(geneSymbol: string): Promise<OrphanetGeneResult[]>` -- CRITICAL: always `.toLowerCase()` on gene symbol. Endpoint: `${ORPHANET_BASE}/rd-associated-genes/genes/symbols/${symbol}`. Returns `data.data.results` (verify field path at implementation). Throws on non-200.

4. `fetchEpidemiology(orphacode: number): Promise<OrphanetPrevalenceEntry[]>` -- Endpoint: `${ORPHANET_BASE}/rd-epidemiology/orphacodes/${orphacode}`. Returns `data.data.results.Prevalence ?? []`. On 404 or any error, return `[]` (not throw -- many subtypes lack epi data per Pitfall 2).

5. `fetchNaturalHistory(orphacode: number): Promise<string[]>` -- Endpoint: `${ORPHANET_BASE}/rd-natural_history/orphacodes/${orphacode}`. Returns `data.data.results.TypeOfInheritance ?? []`. On error, return `[]`.

6. `selectBestPrevalence(entries: OrphanetPrevalenceEntry[]): OrphanetPrevalenceEntry | null` -- Filter/sort logic:
   - PrevalenceType priority: "Point prevalence" first, "Prevalence at birth" second, others last
   - Geographic priority: "Europe" preferred over other values; deprioritize "Specific population"
   - Validation priority: "Validated" before "Not yet validated"
   - Return first entry after sorting, or null if empty array.

7. `selectPrimaryDisease(diseases: OrphanetDisease[]): OrphanetDisease | undefined` -- Filter AR diseases first; if any exist, use only those. Among candidates, sort by highest `bestPrevalence.valMoy` descending. Return first.

8. `fetchOrphanetData(geneSymbol: string): Promise<OrphanetResult>` -- Orchestrator function:
   a. Call fetchDiseasesByGeneSymbol
   b. For each result, extract orphacode and name from `'Preferred term'`
   c. Construct orphanetUrl: `https://www.orpha.net/consor/cgi-bin/OC_Exp.php?lng=en&Expert=${orphacode}` (safe fallback per RESEARCH.md Open Question 2)
   d. For each orphacode, call fetchEpidemiology + fetchNaturalHistory in parallel (Promise.all per code, Promise.allSettled across codes)
   e. For each disease: check if "Autosomal recessive" is in TypeOfInheritance array (exact match, not string parsing per CONTEXT.md)
   f. For each disease: call selectBestPrevalence on epi entries, parse ValMoy to number
   g. Filter out diseases with no name (safety check)
   h. Return OrphanetResult with diseases array, geneSymbol, fetchedAt: Date.now(), error: null
   i. On top-level catch: return OrphanetResult with empty diseases array and error message string

Create `packages/core/src/orphanet/index.ts` -- barrel export:

- Re-export `fetchOrphanetData`, `selectPrimaryDisease`, `selectBestPrevalence` from `./client`
