**useConfirmDialog.ts** -- Create a module-level singleton composable:

1. Define `ConfirmDialogOptions` interface:
   ```typescript
   interface ConfirmDialogOptions {
     title: string;
     message: string;
     confirmText?: string;   // default: 'OK'
     cancelText?: string;    // default: 'Cancel'; set to '' or null to hide cancel button
     confirmColor?: string;  // default: 'primary'; use 'error' for destructive actions
   }
   ```
2. Module-level singleton state (outside the function):
   - `const isVisible = ref(false);`
   - `const options = ref<ConfirmDialogOptions>({ title: '', message: '' });`
   - `let resolvePromise: ((value: boolean) => void) | null = null;`
3. Export `useConfirmDialog()` function returning `{ isVisible, options, ask, confirm, cancel }`:
   - `ask(opts: ConfirmDialogOptions): Promise<boolean>` — sets options, shows dialog, returns Promise
   - `confirm()` — hides dialog, resolves Promise with `true`, nulls resolvePromise
   - `cancel()` — hides dialog, resolves Promise with `false`, nulls resolvePromise
4. **Critical**: Both `confirm()` and `cancel()` MUST set `resolvePromise = null` after calling it, to prevent stale closures on subsequent calls.
5. Export the `ConfirmDialogOptions` type for consumers.

**ConfirmDialog.vue** -- Create a singleton dialog component:

1. Uses `useConfirmDialog()` to access `isVisible`, `options`, `confirm`, `cancel`.
2. Template structure:
   ```
   <v-dialog v-model="isVisible" max-width="400" @click:outside="cancel">
     <v-card>
       <v-card-title>{{ options.title }}</v-card-title>
       <v-card-text>{{ options.message }}</v-card-text>
       <v-card-actions>
         <v-spacer />
         <v-btn v-if="options.cancelText !== ''" variant="text" @click="cancel">
           {{ options.cancelText || 'Cancel' }}
         </v-btn>
         <v-btn :color="options.confirmColor || 'primary'" variant="flat" @click="confirm">
           {{ options.confirmText || 'OK' }}
         </v-btn>
       </v-card-actions>
     </v-card>
   </v-dialog>
   ```
3. Do NOT use the `persistent` prop — backdrop click must dismiss (cancel).
4. Add `data-testid="confirm-dialog"` to the `v-dialog`.

**composables/index.ts** -- Add re-export:

1. Add: `export { useConfirmDialog } from './useConfirmDialog';`
2. Add: `export type { ConfirmDialogOptions } from './useConfirmDialog';`

**App.vue** -- Mount ConfirmDialog singleton:

1. Import `ConfirmDialog` from `@/components/ConfirmDialog.vue`.
2. Place `<ConfirmDialog />` inside `<v-app>`, after the existing dialogs (after `<HistoryDrawer>`). It needs no props or events — it's self-contained via the composable.
