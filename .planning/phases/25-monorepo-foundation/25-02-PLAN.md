  All type files currently use relative imports within the types directory (e.g., `./filter`, `./variant`). These should remain relative — no changes needed for intra-directory imports.

  - `constraint.ts` may have runtime functions (getLoeufInterpretation, getPliInterpretation) — these are fine in types since they're pure functions

  No `@/` import rewiring should be needed in the types directory itself.

  **Step 3 — Update packages/core/src/index.ts barrel:**
  Add re-exports from types:
  ```typescript

  export * from './types/index.js'
  ```
  Note: Use `.js` extension in imports for ESM compatibility with tsdown output.

  **Step 4 — Verify core types compile:**
  ```bash
  cd packages/core && npx tsc --noEmit
  ```
  Fix any compilation errors. The types should compile without Vue/Pinia/villus since they're pure TypeScript types and functions.
