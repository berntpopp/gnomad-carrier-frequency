Add two new exported functions to `packages/core/src/calculations/formatters.ts`:

1. **`frequencyToScientific(frequency: number | null, locale: string = "en-US"): string`**
   - Return "Not detected" for null or 0
   - Use `Intl.NumberFormat` with `notation: "scientific"`, `minimumSignificantDigits: 3`, `maximumSignificantDigits: 3`
   - Use `formatToParts()` to extract mantissa and exponent
   - Convert exponent digits to Unicode superscript using explicit map (NOT a contiguous range):
     ```
     "0": "\u2070", "1": "\u00B9", "2": "\u00B2", "3": "\u00B3",
     "4": "\u2074", "5": "\u2075", "6": "\u2076", "7": "\u2077",
     "8": "\u2078", "9": "\u2079", "-": "\u207B"
     ```
   - Return format: `"4.31 \u00D7 10\u207B\u00B2"` (mantissa x 10^superscript)
   - The mantissa uses locale-aware decimal separator (comma for de-DE, period for en-US)

2. **`frequencyToPerHundredK(frequency: number | null, locale: string = "en-US"): string`**
   - Return "Not detected" for null or 0
   - Multiply frequency by 100,000
   - Format the numerator with `toLocaleString(locale, { minimumFractionDigits: 0, maximumFractionDigits: 1 })`
   - Format the denominator with `(100_000).toLocaleString(locale)` -- this gives "100,000" for en-US, "100.000" for de-DE
   - Return format: `"4,310 / 100,000"` (use regular ASCII spaces around `/` for clipboard-friendliness)

Also export a `DisplayFormat` type from this file: `export type DisplayFormat = "percent" | "ratio" | "scientific" | "per100k";`

Add tests in formatters.test.ts (create if doesn't exist, or extend existing). Test cases:

- `frequencyToScientific(0)` returns "Not detected"

- `frequencyToPerHundredK(0.0431, "de-DE")` returns string containing "4.310" and "100.000"
- `frequencyToPerHundredK(null)` returns "Not detected"
- Existing `frequencyToPercent` and `frequencyToRatio` tests still pass

  - `currentFormat: DisplayFormat` (session-only, initial: "percent")
- Actions:
  - `setCurrentFormat(format: DisplayFormat)` -- sets currentFormat
  - `setDefaultFormat(format: DisplayFormat)` -- sets defaultFormat
  - `resetToDefault()` -- sets currentFormat = defaultFormat
- Persist config: `{ key: "carrier-freq-display-format", storage: localStorage, pick: ["defaultFormat"] }` -- use `pick` NOT `paths` (pinia-plugin-persistedstate v4 API)

- IMPORTANT: The format store must be accessed inside the callback, not at module level, because Pinia stores require the app to be created first. Calling `useFormatStore()` inside `resetWizard()` and inside the watch callback is safe.
