  <action>
Create `PopulationBarChart.vue` as a self-contained Vue 3 SFC with `<script setup lang="ts">`.

**Props interface:**
```typescript
populations: PopulationFrequency[]  // from @gnomad-cf/core/types
globalCarrierFrequency: number | null
gene: string  // for aria-label and export metadata
gnomadVersion: string  // e.g. "v4.1.0" for export metadata
```

**SVG Layout (internal coordinate system):**
- SVG_WIDTH = 600 (internal units, CSS width: 100% for responsive)
- LABEL_WIDTH = 160 (left margin for population labels)
- VALUE_MARGIN = 90 (right margin reserved for value labels)
- BAR_HEIGHT = 20 (desktop), 14 (mobile smAndDown)
- BAR_GAP = 8 (desktop), 4 (mobile)
- TOP_PADDING = 24
- BOTTOM_PADDING = 40
- BAR_AREA = SVG_WIDTH - LABEL_WIDTH - VALUE_MARGIN

**Computed data:**
- `visiblePops`: filter populations where carrierFrequency is not null AND > 0, sort descending by carrierFrequency. Per CONTEXT.md decision: zero-frequency populations are hidden.
- `maxFreq`: Math.max(globalCarrierFrequency ?? 0, ...visiblePops carrier frequencies) — include global in max scale per Pitfall 1 from RESEARCH.md.
- `svgHeight`: TOP_PADDING + visiblePops.length * (BAR_HEIGHT + BAR_GAP) + BOTTOM_PADDING
- `viewBox`: `0 0 ${SVG_WIDTH} ${svgHeight}`
- `barWidth(freq)`: if !freq or !maxFreq return 0, else (freq / maxFreq) * BAR_AREA
- `barY(index)`: TOP_PADDING + index * (BAR_HEIGHT + BAR_GAP)

**Color scheme (Okabe-Ito, colorblind-safe):**
Use `useAppTheme()` for `isDark`. Use `useDisplay()` for `smAndDown`.

```typescript
const CHART_COLORS = {
  light: { normal: '#0072B2', founder: '#D55E00' },
  dark: { normal: '#56B4E9', founder: '#E69F00' },
  publication: { normal: '#0072B2', founder: '#D55E00', bg: '#FFFFFF', text: '#1A1A1A', refLine: '#666666' }
}
```

Compute `barColor(pop)` based on isDark + isFounderEffect.

**SVG template structure:**
1. Background rect: `fill="rgb(var(--v-theme-surface))"` (in-app only)
2. Population label text (left side): `text-anchor="end"`, `x="LABEL_WIDTH - 8"`, `y="barY(i) + BAR_HEIGHT / 2 + 4"`. Use `smAndDown ? pop.code.toUpperCase() : pop.label` for mobile abbreviated labels.
3. Bar rects: `x="LABEL_WIDTH"`, `y="barY(i)"`, `width="barWidth(pop.carrierFrequency)"`, `height="BAR_HEIGHT"`, `fill="barColor(pop)"`, `style="transition: width 0.3s ease"` for animated transitions.
4. Value labels (right of bar): `x="LABEL_WIDTH + barWidth(pop.carrierFrequency) + VALUE_MARGIN_GAP"` where VALUE_MARGIN_GAP = 6, `text-anchor="start"`, use `formatFrequency(pop.carrierFrequency)`.
5. Reference line group (v-if refLineX is not null): vertical dashed `<line>` from TOP_PADDING-4 to svgHeight - BOTTOM_PADDING + 4, `stroke-dasharray="4,3"`, opacity 0.6. Label: "Global: [formatFrequency(globalCarrierFrequency)]" positioned above line.

**Text colors:**
- In-app: `fill="rgb(var(--v-theme-on-surface))"` for labels and values
- Reference line: `stroke="currentColor"` with opacity

**Empty state:** If visiblePops is empty (all zero or no populations), render a centered text message: "No population data available" instead of the SVG chart.

**Accessibility:**
- `role="img"` on SVG element
- `:aria-label="'Carrier frequency by population for ' + gene"` on SVG
- `<title>` element inside SVG for screen readers

**Mobile responsiveness:**
- Import `useDisplay` from vuetify, use `smAndDown` breakpoint
- When smAndDown: BAR_HEIGHT=14, BAR_GAP=4, LABEL_WIDTH=80 (shorter abbreviated codes fit in less space)
- Labels show `pop.code.toUpperCase()` (e.g., "ASJ", "NFE") instead of full names

**Expose SVG ref:** Use `const svgRef = ref<SVGSVGElement | null>(null)` and `defineExpose({ svgRef })` — Plan 02 needs access for export.

Do NOT use any external charting library — pure inline SVG per VIZ-02.
Do NOT use `v-tabs-window` or `v-tabs-window-item` (known Vuetify issues per RESEARCH.md).

Add tooltip functionality to the PopulationBarChart.vue component created in Task 1.

**Tooltip approach:** Custom HTML tooltip div positioned absolutely over the SVG, NOT Vuetify v-tooltip (per RESEARCH.md Pattern 5 note: Vuetify tooltips have limitations with SVG child elements).

**Template structure:**
Wrap the SVG in a `<div style="position: relative">`. Add a tooltip div after the SVG:

```vue
<div
  v-if="tooltipVisible && tooltipPop"
  class="chart-tooltip elevation-4"
  :style="{ left: tooltipX + 'px', top: tooltipY + 'px' }"
>
  <strong>{{ tooltipPop.label }}</strong><br>
  Carrier frequency: {{ formatFrequency(tooltipPop.carrierFrequency) }}<br>
  AC: {{ tooltipPop.alleleCount }} / AN: {{ tooltipPop.alleleNumber?.toLocaleString() ?? '-' }}<br>
  <em v-if="tooltipPop.isFounderEffect" class="text-warning">Founder effect population</em>
</div>
```

**Hover detection on SVG bars:**
Each bar `<g>` group gets `@mouseenter="showTooltip(pop, $event)"` and `@mouseleave="hideTooltip()"`. Also add `style="cursor: pointer"` on bar groups.

```typescript
const tooltipVisible = ref(false)
const tooltipPop = ref<PopulationFrequency | null>(null)
const tooltipX = ref(0)
const tooltipY = ref(0)

function showTooltip(pop: PopulationFrequency, event: MouseEvent | TouchEvent) {
  tooltipPop.value = pop
  tooltipVisible.value = true
  const rect = (event.currentTarget as Element).closest('.chart-container')?.getBoundingClientRect()
  if (!rect) return
  const clientX = 'touches' in event ? event.touches[0].clientX : event.clientX
  const clientY = 'touches' in event ? event.touches[0].clientY : event.clientY
  tooltipX.value = clientX - rect.left + 12
  tooltipY.value = clientY - rect.top - 10
}

function hideTooltip() {
  tooltipVisible.value = false
}
```

**Touch support:**
On bar group, add `@touchstart.prevent="showTooltip(pop, $event)"`. Set a 3-second auto-dismiss timeout on touch:

```typescript
let touchTimeout: ReturnType<typeof setTimeout> | null = null

function showTooltip(pop, event) {
  // ... position logic above ...
  if ('touches' in event) {
    if (touchTimeout) clearTimeout(touchTimeout)
    touchTimeout = setTimeout(hideTooltip, 3000)
  }
}
```

**Tooltip CSS (scoped):**
```css
.chart-tooltip {
  position: absolute;
  background: rgb(var(--v-theme-surface));
  color: rgb(var(--v-theme-on-surface));
  border: 1px solid rgba(var(--v-theme-on-surface), 0.12);
  border-radius: 8px;
  padding: 8px 12px;
  font-size: 0.8125rem;
  line-height: 1.5;
  pointer-events: none;
  z-index: 10;
  white-space: nowrap;
  max-width: 280px;
}
```

Add `chart-container` class to the wrapping div for position reference.

Clean up touchTimeout in `onBeforeUnmount`:
```typescript
import { onBeforeUnmount } from 'vue'
onBeforeUnmount(() => { if (touchTimeout) clearTimeout(touchTimeout) })
```

**Emit:** `defineEmits<{ 'bar-click': [code: string] }>()` — emit when a bar is clicked (for potential future drill-down; the population modal in StepResults can use this).
