**Unit tests (PopulationBarChart.test.ts):**

Follow existing test patterns from FilterPanel.test.ts. Use `mount` from `@vue/test-utils` with Vuetify plugin.

Create test fixtures:
```typescript
const mockPopulations: PopulationFrequency[] = [
  { code: 'nfe', label: 'Non-Finnish European', carrierFrequency: 0.04, alleleCount: 500, alleleNumber: 12500, isLowSampleSize: false, isFounderEffect: false, geneticPrevalence: 0.0004 },
  { code: 'asj', label: 'Ashkenazi Jewish', carrierFrequency: 0.08, alleleCount: 200, alleleNumber: 2500, isLowSampleSize: false, isFounderEffect: true, geneticPrevalence: 0.0016 },
  { code: 'eas', label: 'East Asian', carrierFrequency: 0.01, alleleCount: 50, alleleNumber: 5000, isLowSampleSize: false, isFounderEffect: false, geneticPrevalence: 0.000025 },
  { code: 'afr', label: 'African/African-American', carrierFrequency: 0, alleleCount: 0, alleleNumber: 8000, isLowSampleSize: false, isFounderEffect: false, geneticPrevalence: 0 },
]
```

**Test cases:**

1. `renders SVG with bars for non-zero populations` — mount with mockPopulations, assert SVG element exists, assert 3 `<rect>` bar elements (AFR has 0, should be hidden), assert no bar for AFR population.

2. `sorts bars by frequency descending` — mount, find all population label text elements, assert order is ASJ (0.08), NFE (0.04), EAS (0.01).

3. `applies distinct color to founder effect populations` — mount, find the bar rect for ASJ (founder), assert its fill attribute is the founder color (#D55E00 in light mode or #E69F00 in dark).

4. `renders global reference line when globalCarrierFrequency provided` — mount with globalCarrierFrequency=0.03, assert a `<line>` element with `stroke-dasharray` exists.

5. `hides reference line when globalCarrierFrequency is null` — mount with globalCarrierFrequency=null, assert no dashed line element.

6. `shows empty state when all populations have zero frequency` — mount with populations all having carrierFrequency=0 or null, assert "No population data" text shown, no SVG bars.

7. `displays formatted frequency values` — mount, assert text elements contain frequency values (check that formatFrequency is called — can check for presence of "%" or "1:" text depending on default format).

8. `exposes svgRef via defineExpose` — mount, access `wrapper.vm.svgRef`, assert it's an SVGSVGElement or null (depending on rendering).

Note: The component uses `useDisplayFormat` and `useAppTheme` composables which need Pinia and Vuetify to be initialized. Follow the existing test setup patterns (createTestingPinia, createVuetify). If complex composable mocking is needed, mock at the module level with `vi.mock`.
