Create `useChartExport.ts` composable for SVG and PNG download functionality.

**Publication color constants (same as PopulationBarChart CHART_COLORS.publication):**
```typescript
const PUB_COLORS = {
  background: '#FFFFFF',
  text: '#1A1A1A',
  refLine: '#666666',
  normalBar: '#0072B2',
  founderBar: '#D55E00',
}
```

**Core function: applyPublicationColors(svgEl: SVGSVGElement):**
Walk all elements in the cloned SVG and replace CSS variable fills/strokes with literal hex values:
- Elements with `fill` containing `var(--v-theme-surface)` -> set `fill` to PUB_COLORS.background
- Elements with `fill` containing `var(--v-theme-on-surface)` -> set `fill` to PUB_COLORS.text
- `<line>` elements with stroke containing `currentColor` -> set `stroke` to PUB_COLORS.refLine
- Also force background rect fill to white, all text fills to dark
- Walk using `svgEl.querySelectorAll('*')` and check `getAttribute('fill')` / `getAttribute('stroke')`

**Core function: addPublicationMetadata(svgEl: SVGSVGElement, gene: string, gnomadVersion: string):**
Per RESEARCH.md pattern. Expand the viewBox to add space for title at top and footer at bottom.
- Parse existing viewBox to get current width and height
- Add 30px at top for title, 20px at bottom for footer
- Update viewBox to new height
- Shift all existing content down by 30px (wrap in a `<g transform="translate(0, 30)">`)
- Insert title `<text>` at (8, 20): "[gene] — Carrier Frequency by Population", font-size 14, font-weight bold, fill #1A1A1A
- Insert footer `<text>` at (8, newHeight - 6): "Source: gnomAD [version]   Generated: [YYYY-MM-DD]", font-size 9, fill #666666
- Use system font stack: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- Set `xmlns="http://www.w3.org/2000/svg"` on root element to ensure standalone SVG validity

**downloadSvg(svgEl, gene, gnomadVersion):**
1. Clone SVG: `svgEl.cloneNode(true) as SVGSVGElement`
2. Call `applyPublicationColors(clone)`
3. Call `addPublicationMetadata(clone, gene, gnomadVersion)`
4. Serialize: `new XMLSerializer().serializeToString(clone)`
5. Prepend XML declaration: `'<?xml version="1.0" encoding="UTF-8"?>\n' + svgStr`
6. Create Blob with type `image/svg+xml;charset=utf-8`
7. Create object URL, trigger download via anchor click, revoke URL
8. Use `generateFilename(gene)` from export-utils + `_chart.svg` suffix

**downloadPng(svgEl, gene, gnomadVersion, scale = 2):**
1. Clone SVG, apply publication colors, add metadata (same as SVG)
2. Serialize to string
3. Create Blob -> object URL
4. Create `new Image()`, set `img.onload` BEFORE setting `img.src` (Pitfall 5)
5. In onload: create canvas at `width * scale` x `height * scale`, `ctx.scale(scale, scale)`, `drawImage(img, 0, 0, width, height)`, revoke SVG URL
6. `canvas.toDataURL('image/png')` -> anchor download
7. Get width/height from the cloned SVG's viewBox (parse viewBox string to extract width and height values)
8. Use `generateFilename(gene)` + `_chart.png` suffix

**Composable return:**
```typescript
export function useChartExport() {
  return { downloadSvg, downloadPng }
}
```

**Register in composables/index.ts:**
Add export for `useChartExport` and `UseChartExportReturn` type.

Do NOT use CSS variables in the exported SVG (Pitfall 3). Always clone first, then apply publication colors.
Do NOT set img.src before attaching onload handler (Pitfall 5).
