  <name>Task 2: Rewrite deploy workflow with docs build and merge</name>
  <files>.github/workflows/deploy.yml</files>
  <action>
    Replace the existing `deploy.yml` with the unified build-and-merge workflow. The workflow must:

    1. Trigger on push to `main` and `workflow_dispatch`
    2. Use `oven-sh/setup-bun@v2` (no `bun-version` input — reads from `packageManager` in package.json)
    3. Run `bun install --frozen-lockfile` (not `npm ci`)
    4. Run lint (`bun run lint`) and typecheck (`bun run typecheck`) before building — deploy is self-contained, doesn't trust CI having passed
    5. Build the Vue app: `bun run build` (outputs to `./dist/`)
    6. Build VitePress docs: `bun run docs:build` (outputs to `docs/.vitepress/dist/`)
    7. Merge: `cp -r docs/.vitepress/dist dist/docs`
    8. Configure Pages, upload artifact from `./dist`, deploy

    Keep existing permissions (contents: read, pages: write, id-token: write), concurrency group, and environment settings exactly as they are.

    Use `actions/checkout@v5`, `actions/configure-pages@v5`, `actions/upload-pages-artifact@v4`, `actions/deploy-pages@v4` (same versions currently in use or latest).

    Full workflow content:

    ```yaml
    name: Deploy to GitHub Pages

    on:
      push:
        branches: ['main']
      workflow_dispatch:

    permissions:
      contents: read
      pages: write
      id-token: write

    concurrency:
      group: 'pages'
      cancel-in-progress: true

    jobs:
      deploy:
        environment:
          name: github-pages
          url: ${{ steps.deployment.outputs.page_url }}
        runs-on: ubuntu-latest
        steps:
          - uses: actions/checkout@v5

          - uses: oven-sh/setup-bun@v2

          - name: Install dependencies
            run: bun install --frozen-lockfile

          - name: Lint
            run: bun run lint

          - name: Type Check
            run: bun run typecheck

          - name: Build app
            run: bun run build

          - name: Build docs
            run: bun run docs:build

          - name: Merge docs into artifact
            run: cp -r docs/.vitepress/dist dist/docs

          - name: Configure Pages
            uses: actions/configure-pages@v5

          - name: Upload artifact
            uses: actions/upload-pages-artifact@v4
            with:
              path: './dist'

          - name: Deploy to GitHub Pages
            id: deployment
            uses: actions/deploy-pages@v4
    ```
  </action>
