<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Create SCREENSHOTS_TOKEN repository secret</name>
  <action>
    The screenshot auto-commit workflow needs a Personal Access Token (PAT) to trigger cascade deploys.
    Without this, screenshot auto-commits will still work but won't trigger a redeployment
    (the docs will get updated screenshots on the next regular push to main).
  </action>
  <instructions>
    1. Go to https://github.com/settings/personal-access-tokens/new (Fine-grained token)
    2. Token name: `screenshots-cascade-deploy`
    3. Expiration: 90 days (or longer as preferred)
    4. Repository access: Select "Only select repositories" -> `berntpopp/gnomad-carrier-frequency`
    5. Permissions: Repository permissions -> Contents -> Read and write
    6. Click "Generate token" and copy the token value
    7. Go to https://github.com/berntpopp/gnomad-carrier-frequency/settings/secrets/actions
    8. Click "New repository secret"
    9. Name: `SCREENSHOTS_TOKEN`
    10. Value: Paste the token
    11. Click "Add secret"
  </instructions>
  <resume-signal>Type "secret created" when the SCREENSHOTS_TOKEN repository secret is configured, or "skip pat" if you want to proceed without cascade deploy (screenshots will still auto-commit but won't trigger immediate redeployment)</resume-signal>
</task>
