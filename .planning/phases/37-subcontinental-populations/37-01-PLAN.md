  <action>
1. Create `packages/core/src/queries/subcontinental-variant.ts`:
   - Export a `VARIANT_SUBCONTINENTAL_QUERY` string containing the GraphQL query. The query MUST include `$referenceGenome: ReferenceGenomeId!` to match the gnomAD API schema and the existing GENE_VARIANTS_QUERY pattern in `gene-variants.ts`:
     ```graphql
     query VariantSubcontinental($variantId: String!, $dataset: DatasetId!, $referenceGenome: ReferenceGenomeId!) {
       variant(variant_id: $variantId, dataset: $dataset, reference_genome: $referenceGenome) {
         variant_id
         exome {
           populations {
             id
             ac
             an
             ac_hom
           }
         }
         genome {
           populations {
             id
             ac
             an
             ac_hom
           }
         }
       }
     }
     ```
   - IMPORTANT: Include `$referenceGenome` parameter — the gnomAD GraphQL schema requires it (confirmed in RESEARCH.md and consistent with GENE_VARIANTS_QUERY in gene-variants.ts which also passes `$referenceGenome`). For v2.1.1, this will be "GRCh37".
   - Do NOT request top-level `ac`/`an`/`ac_hom` on exome/genome objects — the composable only needs `populations[].{id,ac,an,ac_hom}`. Omitting top-level fields reduces response payload.
   - Do NOT request the `joint` field — gnomAD v2.1.1 does not have a joint field. Only exome and genome.
   - Export a `VariantSubcontinentalVariables` type: `{ variantId: string; dataset: string; referenceGenome: 'GRCh37' | 'GRCh38'; }`.
   - Export a `VariantSubcontinentalResponse` type for the response shape:
     ```typescript
     export interface VariantSubcontinentalResponse {
       variant: {
         variant_id: string;
         exome: {
           populations: Array<{ id: string; ac: number; an: number; ac_hom: number }>;
         } | null;
         genome: {
           populations: Array<{ id: string; ac: number; an: number; ac_hom: number }>;
         } | null;
       } | null;
     }
     ```

2. In `packages/core/src/queries/index.ts`:
   - Re-export `VARIANT_SUBCONTINENTAL_QUERY`, `VariantSubcontinentalVariables`, and `VariantSubcontinentalResponse` from the new file.
