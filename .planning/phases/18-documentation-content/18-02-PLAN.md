# Carrier Screening Counseling

## The Scenario

2-3 sentences: "A couple is planning their first pregnancy. During pre-conception counseling, one partner was found to carry a pathogenic variant in the CFTR gene (cystic fibrosis). You need to determine the carrier frequency in the partner's population to estimate the couple's recurrence risk."

## Using the Calculator

### Searching for CFTR

Brief: Enter CFTR in the gene search, select from autocomplete. The calculator queries gnomAD for all qualifying variants.

### Reviewing the Variant Table

This is the key teaching moment. When CFTR variants load, the table may include c.1210-11T>G (also known as the 5T allele in the intron 8 polypyrimidine tract). This variant has disputed pathogenicity — some classifications consider it pathogenic only in combination with specific TG tract lengths (TG12 or TG13), while others classify it as benign or of uncertain significance.

Embed variant-table screenshot:
```html

  <figcaption>The variant table lists all qualifying CFTR variants. Each row can be individually included or excluded.</figcaption>
</figure>
```

### Excluding a Variant

Explain: To exclude c.1210-11T>G, uncheck it in the variant table. The calculator recalculates the carrier frequency using only the remaining variants. This is a common clinical decision — the tool supports it directly rather than requiring manual recalculation.

::: tip When to Exclude Variants
Variant exclusion is useful when a variant's pathogenicity is disputed or context-dependent. The calculator lets you see the impact on carrier frequency with and without specific variants. See the [Filters reference](/reference/filters) for details on automatic variant filtering.
:::

### Interpreting Results

Explain: The results show carrier frequencies for each gnomAD population. For carrier screening, focus on the population matching the partner's ancestry. The recurrence risk (with "heterozygous carrier" status) represents the probability that this couple's child would be affected: carrier_freq x carrier_freq x 1/4.

# Recurrence Risk and Family Planning

## The Scenario

2-3 sentences: "A child has been diagnosed with cystic fibrosis. Molecular testing identified two different CFTR variants, confirming compound heterozygosity (though phase has not been formally confirmed by parental testing). The parents want to understand the recurrence risk for future pregnancies."

## Using the Calculator

### Setting Up the Calculation

Brief: Search for CFTR, then select "Compound heterozygous (assumed)" as the patient status. This reflects the clinical reality — two variants detected but phase not formally confirmed. The calculator uses a risk divisor of 1/2 for this status (compared to 1/4 for a heterozygous carrier).

::: info Confirmed vs. Assumed Compound Heterozygosity
If parental testing or long-read sequencing has confirmed the variants are on separate alleles, select "Compound heterozygous (confirmed)." Both options use the same risk formula, but the distinction is documented in the generated clinical text to reflect the level of evidence.
:::

### Understanding the Recurrence Risk

This is the key teaching moment. Explain:
- For compound heterozygous / homozygous patients, the recurrence risk formula is: carrier_frequency / 2
- This is because one parent is an obligate carrier (probability = 1), the partner's carrier probability equals the population carrier frequency, and there is a 1/2 chance both pass on the pathogenic allele
- Compare to heterozygous carrier status where the divisor is /4 (partner must ALSO be a carrier)
- The results table shows this risk for each population — focus on the population matching the family's ancestry

::: tip Population-Specific Values
Carrier frequencies can vary substantially between populations. For CFTR, the non-Finnish European (NFE) carrier frequency is notably higher than in East Asian populations due to founder effects. When the family's ancestry is known, use the population-specific value rather than the global average. See [Methodology](/reference/methodology) for details on population-specific calculations.
:::

- See [Methodology](/reference/methodology) for the full recurrence risk calculation
- See [Clinical Letter](/use-cases/clinical-letter) for generating documentation about these results

# Clinical Letter Generation

## The Scenario

2-3 sentences: "A patient has been tested as part of a family cascade screening and found to carry the HFE C282Y variant (hereditary hemochromatosis). You need to write a clinical letter explaining the carrier status and its reproductive implications. The letter should be in German with gender-inclusive language."

## Using the Calculator

### Setting Up with HFE

Brief: Search for HFE. Unlike CFTR where many variants qualify automatically, HFE typically shows fewer results. For hereditary hemochromatosis carrier screening, you may want to focus specifically on the two clinically relevant variants: C282Y (p.Cys282Tyr) and H63D (p.His63Asp). Use the variant table to activate only these variants if others are included.

### Selecting the Right Perspective

Brief: Set the patient status to "Heterozygous carrier" (the patient carries one C282Y variant). In the results view, select the "Healthy Carrier" perspective for clinical text generation. This perspective produces text appropriate for someone who carries a variant but is not affected — it explains what carrier status means and recommends partner testing.

The three perspectives produce different text:
- **Affected Patient**: For someone with confirmed disease
- **Healthy Carrier**: For an identified carrier (this scenario)
- **Family Member**: For a relative who may want testing

### Generating German Clinical Text

Explain:
- Select German as the output language
- Choose a gender-inclusive style (Asterisk *, Colon :, Slash /, or Traditional)
- The text uses your calculation results automatically — carrier frequency, recurrence risk, gene name, and data source are all substituted into the template
- Review the generated text and adjust settings if needed (click the settings icon to access the template editor)
