    ## Carrier Frequency (carrier-frequency.ts)

    calculateHWECarrierFrequency(pathogenicAFs: number[]): number
    - q = sum of all AFs
    - p = 1 - q
    - returns 2 * p * q
    - Cases:
      - [0.023] -> ~0.04494 (CFTR global approximate)
      - [0.01, 0.005] -> 2 * (1-0.015) * 0.015 = 0.02955
      - [] -> 0
      - [0.001] -> ~0.001998 (converges with simplified for small q)

    calculateSimplifiedCarrierFrequency(pathogenicAFs: number[]): number
    - returns 2 * sum(AFs)
    - Cases:
      - [0.01, 0.005] -> 0.03
      - [] -> 0
      - [0.023] -> 0.046

    ## Homozygote Exclusion (homozygote-exclusion.ts)

    calculateVCR(ac: number, an: number, acHom: number): number
    - VCR = (AC - 2 * acHom) / (AN / 2)
    - Returns 0 if AN === 0
    - Cases:
      - (10, 1000, 0) -> 0.02 (no homozygotes: standard carrier rate)
      - (12, 1000, 1) -> 0.02 (1 homozygote: 12-2=10 het alleles, /500)
      - (0, 0, 0) -> 0 (unsampled)
      - (100, 10000, 5) -> (100-10)/5000 = 0.018

    calculateGCR(vcrs: number[]): number
    - GCR = 1 - product(1 - VCRi)
    - Cases:
      - [0.02] -> 0.02 (single variant = VCR)
      - [0.02, 0.01] -> 1 - 0.98*0.99 = 0.0298
      - [] -> 0
      - [0.02, 0.01, 0.005] -> 1 - 0.98*0.99*0.995 = ~0.03471

    ## Prevalence (prevalence.ts)

    calculateGeneticPrevalence(pathogenicAFs: number[]): number
    - q = sum of AFs, returns q*q
    - IMPORTANT: Always from raw q=SumAF, NOT from carrier frequency
    - Cases:
      - [0.023] -> 0.000529
      - [0.01, 0.005] -> 0.000225
      - [] -> 0

    calculateBayesianPrevalence(geneticPrevalence: number, penetrance: number): number
    - returns geneticPrevalence * penetrance
    - Default penetrance = 1.0
    - Cases:
      - (0.000529, 1.0) -> 0.000529
      - (0.000529, 0.8) -> 0.000529 * 0.8 = 0.0004232
      - (0.000529, 0.0) -> 0

    Also add a formatPrevalence function:

    function formatPrevalence(prevalence: number | null): { ratio: string; percent: string }

    - (null) -> { ratio: 'Not detected', percent: 'Not detected' }

    - (0.000529) -> { ratio: '1:1,890', percent: '0.0529%' }
