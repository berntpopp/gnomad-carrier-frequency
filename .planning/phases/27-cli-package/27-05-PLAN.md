Import:

Export `const batchCommand = new Command('batch')` with:

Argument:
- `<file>` - Path to gene list file (JSON or plain text)

Options (inherits most from query, plus batch-specific):
- `-f, --format <fmt>` - Output format: text|json|tsv (default: 'json' -- NOTE: batch defaults to json, not text, because multi-gene text output is long)
- `--variants` - Include per-variant breakdown
- `-p, --population <id>` - Filter to specific population
- `--gnomad-version <ver>` - gnomAD version (default: 'v4')
- `--hwe` / `--no-hwe` - HWE formula (default: true)
- `--exclude-homozygotes` / `--no-exclude-homozygotes` (default: true)
- `--penetrance <n>` - Penetrance (default: 1.0)
- `-o, --output <path>` - Output file (default: stdout)
- `--concurrency <n>` - Max concurrent API requests (default: 3, parsed with parseInt). Must be 1-10.
- `--fail-fast` - Stop on first gene error (default: false)
- `--lof` / `--no-lof` (default: true)
- `--clinvar` / `--no-clinvar` (default: true)
- `--star-threshold <n>` (default: 2)

Action handler:

1. **Read gene list file:**
   ```typescript
   const content = await readFile(filePath, 'utf-8')
   ```

2. **Auto-detect format (RESEARCH.md pitfall 6):**
   - Try `JSON.parse(content)`:
     - If result is an array of strings: treat as plain gene list
     - If result is an array of objects: treat as structured JSON (each object has at minimum `{ gene: string }`, optionally per-gene overrides like `{ gene: "CFTR", population: "nfe" }`)
     - If parse fails: fall back to plain text (one gene per line, trim whitespace, skip empty lines, skip lines starting with `#`)
   - Validate with zod:
     - `z.array(z.string())` for string arrays
     - `z.array(z.object({ gene: z.string() }).passthrough())` for object arrays

3. **Process genes with p-limit concurrency:**
   ```typescript
   const limit = pLimit(opts.concurrency ?? 3)
   const results: QueryResult[] = []
   const errors: Array<{ gene: string; error: string }> = []
   let completed = 0
   ```

4. **Progress tracking:**
   Use `@clack/prompts` for progress if stdout is a TTY. Import `* as p from '@clack/prompts'`.
   - If TTY: use `p.spinner()` or `p.log.step()` for progress updates
   - If not TTY: use simple stderr progress lines: `process.stderr.write(`\r[${completed}/${total}] Processing ${gene}...`)`

   Note: @clack/prompts v1.0.1 has `progress()` built in. Use it for the progress bar. If `progress()` is not available (API may vary), fall back to spinner + log.step.

   Actually, for maximum reliability, use a simple approach:
   - On TTY: `p.spinner()` with message updates per gene
   - On non-TTY: stderr progress lines

5. **Concurrent processing loop:**
   ```typescript
   const tasks = genes.map(geneEntry =>
     limit(async () => {
       const gene = typeof geneEntry === 'string' ? geneEntry : geneEntry.gene
       try {
         const result = await queryGene(gene, queryOpts)
         results.push(result)
       } catch (err) {
         errors.push({ gene, error: err instanceof Error ? err.message : String(err) })
         if (opts.failFast) throw err  // Propagates to Promise.allSettled
       } finally {
         completed++
         // Update progress
       }
     })
   )

   await Promise.allSettled(tasks)  // Use allSettled so fail-fast doesn't lose results
   ```

   IMPORTANT: Use `Promise.allSettled` (not `Promise.all`) so that when `--fail-fast` throws, we still have partial results and can output them.

6. **Format output:**
   Based on format flag:
   - 'json': `formatJson(results, { includeVariants: opts.variants, pretty: true })` -- pass array
   - 'tsv': `formatTsv(results, { includeVariants: opts.variants })` -- pass array
   - 'text': concatenate `formatText(result)` for each result with separator lines

7. **Write output:**
   If `opts.output`: writeFile. Else: stdout.

8. **Error summary (always printed to stderr):**
   ```

   Processed: 8/10 genes successfully
   Failed (2):
     INVALID_GENE: Gene "INVALID_GENE" not found in gnomAD
     ANOTHER: Network error
   ```
   Print to stderr so it doesn't pollute stdout when piping.

9. **Exit code:**
   - Exit 0 if all genes succeeded
   - Exit 1 if any gene failed (even in skip mode)
   - Exit 2 if fail-fast was triggered
