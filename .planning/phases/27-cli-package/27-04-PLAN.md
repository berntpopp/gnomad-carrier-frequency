  <action>
Create `packages/cli/src/commands/query.ts` using commander v14:

```typescript
import { Command } from 'commander'
```

Export `const queryCommand = new Command('query')` with:

Argument:
- `<gene>` - Gene symbol (e.g. CFTR, HEXA)

Options (from CONTEXT.md requirements):
- `-p, --population <id>` - Filter to specific population (e.g. nfe, european). Resolves aliases via `resolvePopulation()`.
- `-f, --format <fmt>` - Output format: text|json|tsv (default: 'text')
- `--variants` - Include per-variant breakdown in output (default: false)
- `--text` or `--clinical` - Generate clinical documentation text (boolean flag)
- `--language <lang>` - Language for clinical text: de|en (default: 'de')
- `--gnomad-version <ver>` - gnomAD version: v4|v3|v2 (default from user config or 'v4')
- `--hwe` / `--no-hwe` - Use HWE formula (default: true)
- `--exclude-homozygotes` / `--no-exclude-homozygotes` - Apply homozygote exclusion (default: true)
- `--penetrance <n>` - Penetrance fraction 0-1 (default: 1.0, parsed with parseFloat)
- `-o, --output <path>` - Write output to file (default: stdout)
- `--lof` / `--no-lof` - LoF HC filter (default: true)
- `--clinvar` / `--no-clinvar` - ClinVar P/LP filter (default: true)
- `--star-threshold <n>` - ClinVar star threshold (default: 2, parsed with parseInt)

Action handler `async (gene: string, opts) => { ... }`:

1. Load user config: `const userConfig = await loadUserConfig()`
2. Merge config: `const merged = mergeConfig(userConfig, opts)` -- this produces filterConfig, calcConfig, version, format
3. Resolve population alias if provided: `const pop = opts.population ? resolvePopulation(opts.population) : undefined`
4. Call `queryGene(gene, { version: merged.version, filterConfig: merged.filterConfig, calcConfig: merged.calcConfig, population: pop })`
5. Format output based on `merged.format`:
   - 'text': `formatText(result, { includeVariants: opts.variants })`
   - 'json': `formatJson(result, { includeVariants: opts.variants, pretty: true })`
   - 'tsv': `formatTsv(result, { includeVariants: opts.variants })`
6. If `opts.text` or `opts.clinical` flag is set, append clinical text: `await formatClinical(result, { language: opts.language })`
7. Write output:
   - If `opts.output`: write to file using `writeFile` from `node:fs/promises`
   - Else: `process.stdout.write(output + '\n')`
8. Error handling: wrap in try/catch, print error message to stderr, exit with code 1

Use descriptive error messages:
- "Gene not found" -> suggest checking spelling, remind that gene symbols are case-insensitive
- Network error -> suggest checking internet connection
- GraphQL error -> print the server error message
