    Create `packages/core/src/gene-config/` directory with three files:

    **schema.ts** — Define GeneConfigSchema using Zod v4 (already installed at v4.3.5):
    - `DiseaseIdentifierSchema`: z.object with `omimId` (optional, regex `/^\d{6}$/`), `mondoId` (optional, regex `/^MONDO:\d{7}$/`), `name` (string, min 1). Add `.refine()` enforcing at least one of omimId or mondoId is present.
    - `FilterConfigOverrideSchema`: z.object with optional boolean fields `lofHcEnabled`, `missenseEnabled`, `clinvarEnabled`, optional int `clinvarStarThreshold` (0-4), optional boolean `clinvarIncludeConflicting`, optional int `clinvarConflictingThreshold` (50-100). These field names MUST match the existing `FilterConfig` interface in `packages/core/src/types/filter.ts`. Make the entire object optional.
    - `ConditionProfileSchema`: z.object with `profileId` (string min 1), `displayName` (string min 1), `isDefault` (boolean), `disease` (DiseaseIdentifierSchema), optional `penetrance` (number 0-1), optional `filterOverrides` (FilterConfigOverrideSchema), optional `variantExclusions` (array of strings), optional `notes` (string), optional `references` (array of URL strings).
    - `GeneConfigSchema`: z.object with `schemaVersion` (z.literal('1.0')), `geneSymbol` (string min 1 max 20), optional `displayName`, optional `omimGeneId` (regex `/^\d{6}$/`), optional `inheritance` (z.enum(['AR', 'XL', 'AD'])), `profiles` (array of ConditionProfileSchema, min 1). Add `.refine()` enforcing exactly one profile has `isDefault: true`.
    - Export types: `GeneConfig`, `ConditionProfile`, `DiseaseIdentifier` via `z.infer<typeof ...>`.
    - IMPORTANT: Do NOT combine `.default()` with `.optional()` — Zod v4 behavior change. Use `.optional()` alone for optional fields.
    - IMPORTANT: Keep schema self-contained — do NOT import FilterConfig from `../types/filter`. Define FilterConfigOverrideSchema independently to avoid circular imports between tsdown entry points.

    **loader.ts** — Platform-neutral gene config loader:
    - Module-level `registry: Map<string, GeneConfig>` for pre-registered configs.
    - `registerGeneConfig(config: GeneConfig): void` — stores config in registry keyed by `config.geneSymbol.toUpperCase()`.
    - Module-level `platformLoader: ((symbol: string) => Promise<unknown>) | null = null`.
    - `setPlatformLoader(loader: (symbol: string) => Promise<unknown>): void` — sets the platform loader (for CLI fs.readFile use).
    - `loadGeneConfig(symbol: string): Promise<GeneConfig | null>` — (1) check registry by uppercased symbol, return if found; (2) if platformLoader is set, call it, safeParse result with GeneConfigSchema, return data if valid or null with console.warn on error; (3) return null.
    - `getRegisteredGenes(): string[]` — returns array of registered gene symbols (for discoverability).
    - Import GeneConfigSchema from `./schema.js` (use .js extension for ESM compatibility in tsdown output).

    **index.ts** — Barrel:
    - Re-export everything from `./schema.js` and `./loader.js`.

    **Update packages/core/src/index.ts:**
