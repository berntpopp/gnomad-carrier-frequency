  <name>Task 2: Create CI validation script and GitHub Actions workflow</name>

  <action>
    **scripts/validate-gene-configs.ts** — Standalone validation script run by Bun:
    - Import `readdir`, `readFile` from `fs/promises` and `join` from `path`.
    - Import `GeneConfigSchema` directly from `../packages/core/src/gene-config/schema.ts` (Bun runs TS natively, no build needed).
    - Resolve configs dir: `join(import.meta.dir, '../configs/genes')`.
    - List all `.json` files in the directory.
    - If no JSON files found, print message and exit 0.
    - For each JSON file: parse JSON (catch parse errors), run `GeneConfigSchema.safeParse(raw)`.
    - On validation failure: print `FAIL: {filename}` then iterate `result.error.issues` (NOT `.errors` — removed in Zod v4) printing `[{path.join('.')}] {message}` for each issue. Set `hasErrors = true`.
    - On validation success: print `OK: {filename} - {profileCount} profile(s), default: "{defaultProfileDisplayName}"`.
    - After all files: if `hasErrors`, print summary and `process.exit(1)`. Otherwise print "All gene configs valid."
    - Also validate filename convention: filename should match geneSymbol in the config (case-insensitive, e.g., `CFTR.json` should contain `geneSymbol: "CFTR"`). Print warning if mismatch.

    **Run the script** to validate the three seed configs created in Task 1: `bun scripts/validate-gene-configs.ts`. All three should print OK.

    **.github/workflows/validate-gene-configs.yml** — GitHub Actions workflow:
    - Name: "Validate Gene Configs"
    - Triggers: `on: pull_request:` with `paths:` filter for `configs/genes/**`, `packages/core/src/gene-config/**`, and `scripts/validate-gene-configs.ts`.
    - Single job `validate` on `ubuntu-latest`.
    - Steps: checkout@v5, setup-bun@v2, `bun install --frozen-lockfile`, `bun scripts/validate-gene-configs.ts`.
    - Match the style of existing workflows in `.github/workflows/ci.yml` (same checkout/bun versions).
  </action>
  <verify>

  </verify>
