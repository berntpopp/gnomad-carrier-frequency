# Milestone v1.3: Documentation Site

**Status:** SHIPPED 2026-02-23
**Phases:** 16-20
**Total Plans:** 14

## Overview

Professional documentation site with auto-generated screenshots, deployed alongside the app on GitHub Pages. The milestone adds a VitePress-based docs site at /docs/ alongside the existing Vue app, with Playwright-generated screenshots, clinical use cases, reference material, and automated CI/CD for both app and docs deployment.

## Milestone Summary

**Decimal Phases:** None (all phases were planned, no urgent insertions required)

**Key Decisions:**

- VitePress alpha (@next) for Vite 7 compatibility — same Vite/Vue ecosystem, shared node_modules
- Playwright for screenshots — same Node/TS ecosystem, full control over wizard navigation
- Merged deployment artifact — app at root, docs at /docs/, single GitHub Pages deployment
- Fixture-based API mocking — realistic CFTR data for reproducible screenshots
- Clinical-first voice — research tool supporting clinical work, "For Research Use Only" disclaimers
- `<span v-pre>` pattern for VitePress template variable escaping

**Issues Resolved:**

- PWA service worker intercepting /docs/ requests (fixed with navigateFallbackDenylist)
- VitePress alpha processing {{}} in ::: containers (fixed with `<span v-pre>`)
- Base path confusion with custom domain (corrected Open Calculator links to absolute URLs)
- Lighthouse SEO penalty from missing robots.txt (added to public/)

**Issues Deferred:**

- Interactive Vue components in docs (static screenshots sufficient for v1.3)
- Multi-language docs i18n (English docs first)
- Video tutorials (screenshot walkthroughs sufficient)

**Technical Debt Incurred:**

- generate-screenshots.ts spawns `npm run dev` instead of `bun run dev` (works on CI, inconsistent with Bun-first approach)
- Makefile `screenshots` target uses `npx tsx` while CI uses `bunx tsx` (both work correctly)
- Screenshot cascade deploy requires SCREENSHOTS_TOKEN PAT (falls back gracefully)
