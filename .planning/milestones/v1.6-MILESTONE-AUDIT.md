## Tech Debt Details

### 1. Web TSV Export: Empty Quality/Source Columns (Phase 33 → 34)

**Location:** `apps/web/src/utils/export-utils.ts` lines 241-248

`buildVariantsTsv()` outputs empty strings for Stars, Source Category, and Quality Flags columns. Phase 33 created placeholder columns expecting Phase 34 to fill them. Phase 34 created the necessary functions (`classifyVariantSource`, `computeQualityFlags`) and wired them into the UI (VariantTable, FilterPanel), but never connected them to the export pipeline.

**To fix:**
- Add `sourceCategory`, `qualityFlags`, `goldStars` fields to `ExportVariant` type
- Have `buildExportVariants()` call `classifyVariantSource()` and read `qualityFlagsMap`
- Update `buildVariantsTsv()` to emit actual values

### 2. CLI TSV: Empty Quality/Source Columns (Phase 34 CLI)

**Location:** `packages/cli/src/types.ts` lines 15-16, `packages/cli/src/utils/gene-query.ts`

`VariantDetail.sourceCategory` and `qualityFlags` are declared with "Phase 34 will populate" comments but never set. The TSV formatter references them and emits empty strings.

**To fix:**
- Call `computeQualityFlags()` and `classifyVariantSource()` in `gene-query.ts` when building `VariantDetail` objects

### 3. E2E Test Gap: Chart Download Buttons (Phase 35)

**Location:** `apps/web/e2e/phase35-bar-chart.spec.ts` lines 144-160

Tests 2 and 3 assert SVG/PNG download button visibility without first clicking the Chart tab. The Chart `v-window-item` is not rendered when the default Table tab is active, so these tests would fail in a real browser.

**To fix:**
- Add chart tab click (`page.click('[data-testid="chart-tab"]')`) before asserting download button visibility

### 4. Dead Code: setDefaultFormat Action (Phase 33)

**Location:** `apps/web/src/stores/useFormatStore.ts` line 29

`setDefaultFormat()` action is defined but never called. `SettingsDialog` mutates `formatStore.defaultFormat` directly via `v-model` (valid in Pinia Options Store). Minor dead code.

## Summary

All 47 v1.6 requirements are satisfied. All 5 phases pass verification. The milestone delivers its core value: quality flags, source breakdown, display formats, TSV export, Orphanet prevalence, subcontinental populations, and bar chart visualization all work correctly in the UI.

The tech debt is limited to **export pipeline data gaps** — the TSV/JSON/Excel export files have correct column headers for quality and source data but emit empty values because the Phase 33 → 34 export wiring was never completed. This affects downstream bioinformatics consumers but not the interactive web UI, where quality flags and source badges display correctly.
