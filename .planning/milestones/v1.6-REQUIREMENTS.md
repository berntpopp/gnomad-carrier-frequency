## v1.6 Requirements

### Variant Quality Flags

- [x] **QUAL-01**: Variants with AF >= 5% in any population flagged as "High AF (BA1)" with colored chip in variant table
- [x] **QUAL-02**: Variants with unexpectedly high homozygote counts flagged as "High Hom" with chip in variant table
- [x] **QUAL-03**: Variants that failed gnomAD quality filters flagged as "gnomAD Filtered" with chip in variant table
- [x] **QUAL-04**: Variants present only in genome data (no exome) flagged as "Genomes Only" with chip in variant table
- [x] **QUAL-05**: Quality flag thresholds configurable in settings (High AF default: 5%, configurable)
- [x] **QUAL-06**: Summary count of flagged variants displayed in results overview
- [x] **QUAL-07**: Option to exclude flagged variants from carrier frequency calculation (per flag type)
- [x] **QUAL-08**: Tooltip on each flag explaining why it was raised and what the user should consider

### ClinVar vs pLoF Source Breakdown

- [x] **SRC-01**: Each variant classified into non-overlapping source category: ClinVar-only, pLoF-only, or Both
- [x] **SRC-02**: Source category displayed as badge/tag in variant table
- [x] **SRC-03**: Carrier frequency split shown by source: ClinVar-only contribution, pLoF-only contribution, Both contribution
- [x] **SRC-04**: Per-population source breakdown available in results
- [x] **SRC-05**: Source classification function separate from existing filter pipeline (no modification to shouldIncludeVariantConfigurable)

### Display Formats

- [x] **FMT-01**: Display format selector with 4 options: Percentage, Ratio (1:N), Scientific notation, Per 100,000
- [x] **FMT-02**: Scientific notation displayed as Unicode superscript (e.g., 4.31 x 10^-2)
- [x] **FMT-03**: Per-100,000 format displayed as "X / 100,000" (e.g., 4,310 / 100,000)
- [x] **FMT-04**: Selected format applied to population table, summary card, and export output
- [x] **FMT-05**: Format preference persisted in Pinia store (not CalcConfig)
- [x] **FMT-06**: Locale-aware formatting (German comma decimal, English period decimal)
- [x] **FMT-07**: Clinical text templates adapt to selected display format — N/A (clinical text always dual format per design decision)

### TSV Export

- [x] **EXP-01**: "Download TSV" button alongside existing JSON/Excel export options
- [x] **EXP-02**: Population summary TSV with columns: Population, Carrier Frequency, Ratio, Recurrence Risk, AC, AN, Notes
- [x] **EXP-03**: Variant detail TSV with columns: Variant ID, Consequence, AF, Carrier Frequency, ClinVar Significance, Stars, HGVS-c, HGVS-p, Source Category, Quality Flags
- [x] **EXP-04**: UTF-8 BOM prefix for Excel compatibility on Windows with German characters
- [x] **EXP-05**: TSV output available in CLI via `--format tsv` (already exists -- verify compatibility with new columns)

### Orphanet Prevalence

- [x] **ORPH-01**: Orphanet prevalence data fetched via API for the selected gene (api.orphadata.com)
- [x] **ORPH-02**: All associated Orphanet diseases displayed with their prevalence ranges
- [x] **ORPH-03**: Prevalence shown as reference card in results step alongside calculated carrier frequency
- [x] **ORPH-04**: Link to Orphanet entry for each disease
- [x] **ORPH-05**: Orphanet client module in @gnomad-cf/core (platform-neutral, fetch-based)
- [x] **ORPH-06**: Response caching (same gene not fetched twice per session)
- [x] **ORPH-07**: Graceful degradation when Orphanet API is unavailable (offline PWA, API errors)
- [x] **ORPH-08**: Clear disclaimer that Orphanet prevalence reflects reported clinical prevalence, not genetic prevalence

### Subcontinental Populations

- [x] **SUBP-01**: Toggle "Show subcontinental populations" in results view (default: off)
- [x] **SUBP-02**: Subcontinental data displayed for gnomAD v2.1.1 queries only (NFE: 6 subgroups, EAS: 3 subgroups)
- [x] **SUBP-03**: Subgroups nested under parent continental population in frequency table
- [x] **SUBP-04**: Founder effect detection and low sample size warnings applied to subpopulations
- [x] **SUBP-05**: Subcontinental population definitions added to gnomad.json config
- [x] **SUBP-06**: Progress indicator during subcontinental data loading (per-variant queries)
- [x] **SUBP-07**: UI clearly indicates subcontinental data is v2.1.1 only (hidden/disabled for v4 queries)

### Population Bar Chart

- [x] **VIZ-01**: Horizontal bar chart showing carrier frequency per population in results step
- [x] **VIZ-02**: Implemented as inline SVG (zero external dependencies)
- [x] **VIZ-03**: Global frequency shown as reference line
- [x] **VIZ-04**: Founder effect populations visually distinguished (different color or annotation)
- [x] **VIZ-05**: Responsive design (horizontal bars work on mobile)
- [x] **VIZ-06**: Respects Vuetify theme (dark/light mode colors)
- [x] **VIZ-07**: Chart downloadable as SVG for publication use
