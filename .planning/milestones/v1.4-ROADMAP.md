# Milestone v1.4: Discoverability & Polish

**Status:** SHIPPED 2026-02-23
**Phases:** 21-24
**Total Plans:** 12

## Overview

Fix Google indexing with static HTML seed content and structured data, improve CTA visibility with WCAG-compliant color system, add first-time onboarding experience, and expand documentation with educational content pages.

**Goal**: Google can discover, index, and display the site with rich results; social media platforms render correct preview cards

**Requirements**: SEO-01 through SEO-12, SOP-01 through SOP-05
**Plans**: 4 plans

Plans:

## Milestone Summary

**Key Decisions:**

- Title leads with "Carrier Frequency Calculator" not "gnomAD" (primary search term)
- seed-* CSS class prefix for pre-mount styles (avoids Vuetify conflicts)
- Light primary #117A7F, dark primary #4DB6AC (both WCAG AA)
- useGeneSearch singleton promotion for prefillGene access
- Module-level singleton refs in useConfirmDialog
- Concepts nav entry placed between Use Cases and Reference

**Issues Resolved:**

- Site invisible to Google (empty body) — fixed with 750-word static HTML seed
- CTA buttons looked disabled (muted primary color) — fixed with teal primary system
- No first-time user guidance — fixed with WelcomeCard onboarding
- Native alert/confirm inconsistent with app theme — fixed with useConfirmDialog

**Issues Deferred:**

- 12 human verification items requiring live browser/external tool testing (Google Rich Results, social card rendering, WCAG contrast in browser, etc.)

**Technical Debt Incurred:**

- "Advances wizard" success criterion vs "pre-fills gene search" requirement — implementation pre-fills and enables Continue but doesn't auto-advance (design choice, not gap)
