# Citation

If you use the gnomAD Carrier Frequency Calculator in your research, please cite it using one of the formats below.

## How to Cite

Plain-text citation:

> Popp, B. (2026). gnomAD Carrier Frequency Calculator (Version 1.2.0) [Software]. https://gnomad-carrier-frequency.kidney-genetics.org/

## CITATION.cff

This repository includes a `CITATION.cff` file following the [Citation File Format](https://citation-file-format.github.io/) standard. GitHub recognizes this file and provides a "Cite this repository" button on the repository page.

```yaml
cff-version: 1.2.0
message: "If you use this software, please cite it as below."
title: "gnomAD Carrier Frequency Calculator"
type: software
authors:
  - family-names: Popp
    given-names: Bernt
    orcid: "https://orcid.org/0000-0002-3679-1081"
version: 1.2.0
date-released: "2026-01-20"
url: "https://gnomad-carrier-frequency.kidney-genetics.org/"
repository-code: "https://github.com/berntpopp/gnomad-carrier-frequency"
license: MIT
keywords:
  - carrier-frequency
  - gnomad
  - autosomal-recessive
  - genetic-counseling
  - hardy-weinberg
abstract: "A browser-based calculator for carrier frequencies and recurrence risks of autosomal recessive conditions using population data from the Genome Aggregation Database (gnomAD)."
```
