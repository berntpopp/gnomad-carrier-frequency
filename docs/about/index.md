# About

The gnomAD Carrier Frequency Calculator is an open-source research tool for calculating carrier frequencies and recurrence risks of autosomal recessive conditions from gnomAD population data.

## The Project

Built to support clinical documentation workflows, the calculator queries the Genome Aggregation Database (gnomAD) directly from the browser and generates ready-to-use clinical text in German and English. It is designed for genetic counselors, clinical geneticists, and researchers working with autosomal recessive conditions. No server-side processing is required — all calculations run locally in the browser.
