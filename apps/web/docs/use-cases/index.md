# Use Cases

These scenarios demonstrate the calculator using hypothetical examples. Each walks through key steps - focusing on the reasoning behind each decision, not just the clicks.

::: warning For Research Use Only
This tool is intended for research and educational purposes. It is not a validated clinical diagnostic tool. Any outputs must be independently verified by qualified professionals before use in a clinical context.
:::

## Scenarios

Each use case covers a different context and highlights a different set of calculator features.

### [Carrier Screening Example](/use-cases/carrier-screening)

A hypothetical scenario where one individual is a known CFTR carrier. Demonstrates searching for a gene, reviewing the variant table, and excluding a variant with disputed pathogenicity (c.1210-11T>G).

**Key features:** Variant table, individual variant exclusion, heterozygous carrier risk.

### [Text Generation](/use-cases/clinical-letter)

Demonstrates how to generate text output for documentation purposes using HFE as an example. Covers selective variant inclusion, German text generation with gender-inclusive language, and template customization.

**Key features:** Selective variant inclusion, German output, text perspectives, template sections.
